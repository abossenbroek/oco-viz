Void/environment design via the matte-artist agent (read-only).

## Agent

Load matte-artist from `.claude/plugins/vfx-artist-studio/agents/matte-artist.md`.

## Skills

Agent loads environment skills from `.claude/plugins/vfx-artist-studio/skills/environment/`.

## Output

Void quality specification, boundary dissolution parameters, and derived format
composition notes.

$ARGUMENTS: `<shot-id>`, optional `--format` for derived format design.
