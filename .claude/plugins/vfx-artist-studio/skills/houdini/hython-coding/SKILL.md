# Hython Coding -- Batch Scripting Patterns for the oco-viz Pipeline

All Houdini work in the oco-viz pipeline runs in `hython` batch mode. There is no
interactive GUI. Every node network is generated programmatically, every parameter is
set in code, and every cook is validated before the scene is saved. Hand-edited .hip
files are not reproducible, not version-controllable, and not acceptable in a pipeline
that must produce identical results across scout, preview, and final tiers.

> "If it cannot be scripted, it cannot be farmed."

---

## Principle

Hython is Houdini's batch Python interpreter. It provides the full `hou` module without
launching the GUI, enabling headless scene construction on both Mac development machines
and Linux render farm nodes. Every oco-viz Houdini operation -- VDB import, SOP processing,
USD assembly, Karma ROP configuration -- is authored as a Hython script. The script is
the source of truth, not the .hip file. The .hip file is an artifact generated by the
script, regenerable at any time.

---

## Procedure

### Step 1 -- Script Structure

Every Hython batch script follows this structure:

| Section | Purpose |
|---------|---------|
| Shebang + docstring | `#!/usr/bin/env hython` and module-level docstring |
| Imports | `hou` module, standard library, project utilities |
| Node network generation | Programmatic creation of the entire node graph |
| Parameter setting | Every parameter set via `parm().set()` with explicit values |
| Validation | Node cook + output verification before saving |
| Save | Write .hip file only after all validation passes |

### Step 2 -- Node Creation Patterns

All nodes are created through the `hou` module API:

| Operation | Pattern |
|-----------|---------|
| Get context root | `obj = hou.node("/obj")` |
| Create container | `geo = obj.createNode("geo", "node_name")` |
| Create SOP | `node = geo.createNode("sop_type", "node_name")` |
| Set parameter | `node.parm("parm_name").set(value)` |
| Set string parm | `node.parm("file").set("/path/to/file.vdb")` |
| Set expression | `node.parm("tx").setExpression("ch('../other/tx')")` |
| Connect nodes | `downstream.setInput(0, upstream)` |
| Cook node | `node.cook(force=True)` |
| Set display/render | `node.setDisplayFlag(True)` and `node.setRenderFlag(True)` |

### Step 3 -- Error Handling

Hython scripts must handle Houdini-specific exceptions:

| Exception | Cause | Response |
|-----------|-------|----------|
| `hou.OperationFailed` | Node cook failure, invalid parameter | Log diagnostic, abort with non-zero exit |
| `hou.NodeError` | Node-level error during cook | Inspect `node.errors()`, log, abort |
| `hou.ObjectWasDeleted` | Accessing a deleted node reference | Defensive check before access |
| `ValueError` | Invalid parameter value | Validate inputs before `parm().set()` |

### Step 4 -- Validation Before Save

Every script validates its output before writing the .hip file:

1. Cook all output nodes with `force=True`.
2. Check `node.errors()` and `node.warnings()` on every node.
3. Verify geometry/volume data exists: `node.geometry().prims()` is non-empty.
4. For VDB workflows, verify grid names match pipeline convention.
5. Only call `hou.hipFile.save()` after all checks pass.

## Verified Code Templates

### Basic Hython Batch Script

```python
#!/usr/bin/env hython
"""Batch script: import VDB, process, export."""
from __future__ import annotations

import sys

import hou  # type: ignore[import-untyped]


def main() -> int:
    """Build node network, process, and save."""
    # Create fresh scene
    hou.hipFile.clear(suppress_save_prompt=True)

    # Build network
    obj = hou.node("/obj")
    geo = obj.createNode("geo", "vdb_process")
    geo.moveToGoodPosition()

    # Import VDB
    file_node = geo.createNode("file", "vdb_import")
    file_node.parm("file").set("/path/to/input.vdb")

    # Process
    vdb_smooth = geo.createNode("vdbsmooth", "smooth")
    vdb_smooth.parm("iterations").set(3)
    vdb_smooth.setInput(0, file_node)

    # Output
    output = geo.createNode("null", "OUT")
    output.setInput(0, vdb_smooth)
    output.setDisplayFlag(True)
    output.setRenderFlag(True)

    # Validate
    try:
        output.cook(force=True)
    except hou.OperationFailed as exc:
        print(f"ERROR: Cook failed: {exc}", file=sys.stderr)
        return 1

    errors = output.errors()
    if errors:
        print(f"ERROR: Node errors: {errors}", file=sys.stderr)
        return 1

    geo_data = output.geometry()
    if not geo_data or len(geo_data.prims()) == 0:
        print("ERROR: No primitives in output", file=sys.stderr)
        return 1

    # Save
    hou.hipFile.save("/path/to/output.hip")
    print("SUCCESS: Scene saved")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

### VDB Import + Process + Export

```python
#!/usr/bin/env hython
"""Import OpenVDB, apply SOP processing, export processed VDB."""
from __future__ import annotations

import sys
from pathlib import Path

import hou  # type: ignore[import-untyped]

EXPECTED_GRIDS = ["density", "vel", "temperature"]


def build_vdb_pipeline(
    vdb_input: str,
    vdb_output: str,
) -> hou.Node:
    """Build VDB processing pipeline and return output node."""
    obj = hou.node("/obj")
    geo = obj.createNode("geo", "vdb_pipeline")

    # Import
    file_in = geo.createNode("file", "import")
    file_in.parm("file").set(vdb_input)

    # Validate grids after import
    file_in.cook(force=True)
    found = [p.attribValue("name") for p in file_in.geometry().prims()]
    for grid in EXPECTED_GRIDS:
        if grid not in found:
            msg = f"Missing grid '{grid}'. Found: {found}"
            raise ValueError(msg)

    # Smooth density
    smooth = geo.createNode("vdbsmooth", "smooth_density")
    smooth.parm("iterations").set(2)
    smooth.parm("group").set("@name=density")
    smooth.setInput(0, file_in)

    # Resample for consistent voxel size
    resample = geo.createNode("vdbresample", "resample")
    resample.parm("voxelsize").set(0.01)  # meters
    resample.setInput(0, smooth)

    # Export
    file_out = geo.createNode("file", "export")
    file_out.parm("file").set(vdb_output)
    file_out.parm("filemode").set(2)  # write mode
    file_out.setInput(0, resample)

    file_out.setDisplayFlag(True)
    file_out.setRenderFlag(True)

    return file_out


def main() -> int:
    """Run VDB processing pipeline."""
    vdb_input = sys.argv[1] if len(sys.argv) > 1 else ""
    vdb_output = sys.argv[2] if len(sys.argv) > 2 else ""

    if not vdb_input or not Path(vdb_input).exists():
        print(f"ERROR: Input VDB not found: {vdb_input}", file=sys.stderr)
        return 1

    hou.hipFile.clear(suppress_save_prompt=True)

    try:
        output_node = build_vdb_pipeline(vdb_input, vdb_output)
        output_node.cook(force=True)
    except (hou.OperationFailed, ValueError) as exc:
        print(f"ERROR: Pipeline failed: {exc}", file=sys.stderr)
        return 1

    print(f"SUCCESS: Processed VDB written to {vdb_output}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

### SOP Network Generation

```python
"""Generate a SOP network programmatically for volume processing."""
from __future__ import annotations

import hou  # type: ignore[import-untyped]


def create_volume_sop_network(
    parent: hou.Node,
    vdb_path: str,
    voxel_size: float = 0.01,
) -> hou.Node:
    """Build a reusable SOP chain for volume processing.

    Parameters
    ----------
    parent : hou.Node
        Parent geo node.
    vdb_path : str
        Path to input VDB file.
    voxel_size : float
        Target voxel size in meters.

    Returns
    -------
    hou.Node
        The final output null node.
    """
    # Import
    file_node = parent.createNode("file", "vdb_in")
    file_node.parm("file").set(vdb_path)

    # Activate (ensure proper active region)
    activate = parent.createNode("vdbactivate", "activate")
    activate.parm("group").set("@name=density")
    activate.setInput(0, file_node)

    # Combine multiple grids if needed
    combine = parent.createNode("vdbcombine", "combine")
    combine.setInput(0, activate)

    # Output null
    out = parent.createNode("null", "OUT")
    out.setInput(0, combine)
    out.setDisplayFlag(True)
    out.setRenderFlag(True)

    # Layout
    parent.layoutChildren()

    return out
```

## Parameters

### Script Execution Parameters

| Parameter | Type | Default | Range | Description |
|-----------|------|---------|-------|-------------|
| `hip_version` | string | 20.5 | -- | Minimum Houdini version required |
| `hython_path` | string | /opt/hfs/bin/hython | -- | Absolute path to hython binary |
| `batch_timeout` | int | 3600 | 300 - 7200 | Maximum script execution time in seconds |
| `exit_on_error` | bool | true | -- | Exit with non-zero code on any error |
| `save_hip` | bool | true | -- | Save .hip file after successful processing |

### Node Network Parameters

| Parameter | Type | Default | Range | Description |
|-----------|------|---------|-------|-------------|
| `auto_layout` | bool | true | -- | Call layoutChildren() after network creation |
| `cook_timeout` | int | 600 | 60 - 3600 | Per-node cook timeout in seconds |
| `force_cook` | bool | true | -- | Always cook with force=True for determinism |

## Anti-Patterns

### 1. The Interactive Session

**Symptom:** A script works when run inside Houdini's Python shell but fails under
`hython`. Dialog boxes pop up, nodes require manual interaction, or the script expects
a viewport.

**Cause:** Writing scripts that depend on the Houdini GUI -- using `hou.ui` calls,
relying on viewport feedback, or skipping `suppress_save_prompt=True` on file operations.

**Fix:** All scripts must run headlessly under `hython`. Never call `hou.ui` functions.
Always pass `suppress_save_prompt=True` to `hipFile.clear()` and `hipFile.save()`.
Test scripts via `hython script.py` on the command line, never by pasting into the
Houdini Python shell.

### 2. The Hand-Written .hip File

**Symptom:** A .hip file exists that was created interactively in the Houdini GUI.
Nobody knows exactly what parameters were set. Different versions of the .hip file
produce different results with no clear changelog.

**Cause:** Using the GUI as the authoring environment instead of code. The .hip file
becomes the source of truth, but it is a binary format that cannot be diffed, reviewed,
or version-controlled meaningfully.

**Fix:** The Hython script is the source of truth. The .hip file is a generated artifact.
If the .hip file is lost, the script regenerates it identically. Every parameter is
set explicitly in code with a visible value. Never hand-edit .hip files for production
work.

### 3. The Missing Validation

**Symptom:** A script runs without errors but produces an empty or corrupt .hip file.
Downstream tools fail with cryptic messages. The script author says "it worked on my
machine."

**Cause:** No validation between node creation and file save. The script assumes that
if no Python exception was raised, everything is correct.

**Fix:** Cook every output node with `force=True`. Check `node.errors()` and
`node.warnings()`. Verify geometry exists and contains expected primitives. For VDB
workflows, verify grid names match pipeline convention. Only save after all checks pass.
Exit with non-zero code on any failure.

### 4. The Hardcoded Path

**Symptom:** A script works on the author's machine but fails on the render farm or
a colleague's workstation because file paths are hardcoded to a specific directory
structure.

**Cause:** Embedding absolute paths like `/Users/artist/projects/shot_01/vdb/` instead
of accepting paths as arguments or reading them from configuration.

**Fix:** Accept all file paths as command-line arguments or environment variables.
Use `pathlib.Path` for path manipulation. Validate that input files exist before
processing. Use `$HIP` or `$JOB` Houdini variables for relative scene references.

## Validation Checklist

- [ ] Script runs under `hython` (not interactive Houdini GUI)
- [ ] Shebang line: `#!/usr/bin/env hython`
- [ ] Module docstring describing the script's purpose
- [ ] `from __future__ import annotations` at top of file
- [ ] All nodes created via `hou` API (no manual .hip editing)
- [ ] Every parameter set explicitly via `parm().set()` with visible value
- [ ] `hou.hipFile.clear(suppress_save_prompt=True)` at script start
- [ ] All output nodes cooked with `force=True`
- [ ] `node.errors()` checked on every cooked node
- [ ] Geometry/primitive count verified (non-empty output)
- [ ] VDB grid names validated against pipeline convention
- [ ] `hou.OperationFailed` caught and handled with diagnostic output
- [ ] Script exits with non-zero code on any failure
- [ ] File paths accepted as arguments (not hardcoded)
- [ ] .hip file saved only after all validation passes
