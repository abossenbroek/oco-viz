# Narrative Potency -- Emotional Arc Gate

Does the temporal evolution create tension and release? The long-form state
machine must produce genuine narrative weight, not mere animation.

---

## Criteria

| Criterion | Threshold | Evidence Required |
|-----------|-----------|-------------------|
| Phase identification | All 4 phases present (Quiescent -> Building -> Chaotic -> Aftermath) | Temporal analysis of density/turbulence metrics |
| Phase transitions | Gradual overlap (10-15% duration), no hard cuts | Frame-to-frame difference analysis |
| Tension arc | Measurable intensity increase Building -> Chaotic | Density variance or turbulence energy metrics |
| Release quality | Aftermath != Quiescent (something remains) | End-state vs start-state comparison |
| Emotional engagement | Viewer holds attention >= 5 minutes | Subjective duration assessment |
| Confrontation | Viewer feels implicated, not merely observing | Artistic verdict |
| Breath cycle | Periodic contraction/expansion visible | Temporal volume measurement |
| Pacing | Exhibition: heavy ease-in, geological pace | Motion curve analysis |

---

## Assessment

| Level | Description |
|-------|-------------|
| PASS | All four phases identifiable with gradual transitions. Tension arc builds to genuine climax. Aftermath carries residual weight. Viewer engagement sustained. |
| CONCERN | Phases present but transitions too abrupt or too gradual. Tension arc flat in places. Aftermath too similar to Quiescent. Engagement uncertain beyond 3 minutes. |
| FAIL | Phases missing or indistinguishable. No tension arc. Looping without narrative progression. Viewer disengages within 2 minutes. Animation without meaning. |
