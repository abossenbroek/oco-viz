# Compositional Authority -- Frame Command Gate

The frame commands attention. Asymmetry, void tension, and vertical emphasis
create a composition that holds the viewer. Not containment -- command.

---

## Criteria

| Criterion | Threshold | Evidence Required |
|-----------|-----------|-------------------|
| Asymmetry | Mass center offset >= 0.03 from frame center | Center-of-mass measurement (normalized coordinates) |
| Frame fill | 60-80% (exhibition), 30-90% (study) | Non-black pixel count / total pixels |
| Void quality | Active negative space (not mere absence) | Artistic verdict -- void presses, counterweights |
| Edge discipline | Frame edges absolute black (exhibition) | Edge pixel sampling (5% border region) |
| Vertical emphasis | Rising composition, slight upward angle | Frame analysis -- mass distribution vertical bias |
| Multi-angle resilience | Composition holds from +/-30 deg viewing angle | Multi-viewpoint composition check |
| No clipping | Volume does not touch or exceed frame edges | Boundary pixel check |

---

## Assessment

| Level | Description |
|-------|-------------|
| PASS | Mass deliberately off-center. Frame fill within range. Void active and counterweighting mass. Edges absolute black. Vertical emphasis creates rising industrial dread. Composition holds across viewing cone. |
| CONCERN | Asymmetry present but subtle. Frame fill at boundary of range. Void present but passive. Edges near-black. Vertical emphasis weak. Composition holds from center but weakens at cone edges. |
| FAIL | Mass centered. Frame underfilled (< 30%) or overfilled (> 90%). No void quality -- dead background. Edges contaminated. Horizontal or directionless composition. Composition breaks from off-center viewing. |
